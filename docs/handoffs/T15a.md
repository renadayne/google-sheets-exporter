# T15a — Pure Single-Cell Value Projection and Validation

Status: **PASS for offline pure single-cell projection and validation (T15a)**.

## Delivered Files

- `src/domain/cell.ts` (243 lines):
  - `projectCell(input: unknown, r: number, c: number, mode: ExportMode): Cell | null`: Pure projection validating safe nonnegative integer coordinates `r, c` and selected source representations.
  - Returns fresh plain explicit domain `Cell` objects without spreading raw API properties or mutating inputs.
  - Distinguishes empty cells (`{}` or formatting-only) returning `null` from explicit empty strings (`stringValue: ''`) returning string cells.
  - Mode `raw`: extracts `effectiveValue` union (`numberValue`, `stringValue`, `boolValue`, `errorValue`). Dates stay numeric serials. Rejects invalid `formulaValue` on `effectiveValue`.
  - Mode `formatted`: requires supplied `formattedValue` string on value-bearing cells; never guesses formatting or converts to blank.
  - Mode `formula_text`: only explicit `userEnteredValue.formulaValue` yields formula metadata (`formulaText`); nonformula cells retain raw typed values. Ordinary strings starting with `=` remain ordinary strings.
  - Accompanies `numberFormatType` only when supplied in `effectiveFormat`; no fallback to user-entered formatting or Date casting.
  - Spreadsheet error values (`errorValue {type, message}`) are mapped to data cell `{code: type, message}` without promoting them into thrown diagnostic exceptions or logs.
  - Rejects invalid coordinates with `RANGE_INVALID`. Rejects invalid structures, malformed unions, nonfinite numbers, wrong types, and missing representations with `SOURCE_UNSUPPORTED`.
- `tests/unit/cell.test.ts` (246 lines, 6 tests):
  - Validates all 10 reviewed oracle cells from fidelity fixture in all 3 modes against independent expected literals.
  - Tests blanks, formatting-only, explicit empty strings, formulas returning empty strings, currency, bool false, zero, negative numbers, date serials, tagged errors, and ordinary strings starting with `=`.
  - Tests preservation of exact Unicode, CRLF, quotes, leading zeros, and token-like strings without redaction.
  - Verifies input immutability (`Object.freeze`) and strict suppression of unselected/raw API properties.
  - Tests negative cases for `RANGE_INVALID` (negative, -0, non-integer, NaN, Infinity, unsafe integer coordinates) and `SOURCE_UNSUPPORTED` (primitives, arrays, malformed unions, nonfinites, wrong types, missing formattedValue, missing effectiveValue, invalid modes).

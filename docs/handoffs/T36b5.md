# T36b5 — Safe Worker Staged Artifacts Parser

Pure parser capturing staged artifact snapshots across the worker postMessage boundary.

Files:
- `src/runtime/worker-artifacts.ts`
- `tests/unit/worker-artifacts.test.ts`
- `docs/handoffs/T36b5.md`

`parseWorkerArtifacts(input: unknown, options: { readonly maxArtifacts: number; readonly maxBytes: number }): readonly Artifact[] | null`:
- Pure parser: zero side-effects, timers, network, publication, or memory alloc/copy of binary payloads. Hostile traps/proxies return `null` safely without leaking raw diagnostics.
- Options captured once: `maxArtifacts` (1..4096 safe integer, no -0), `maxBytes` (0..64MiB safe integer, no -0).
- Array input validated before element access: safe length 1..maxArtifacts, exact own indices 0..n-1, no sparse/inherited/accessor slots, symbols, or auth fields.
- Records: plain object/null record, exact 5 own enumerable data keys (`filename`, `mimeType`, `data`, `byteLength`, `safeSummary`), one own-keys snapshot and one descriptor capture per key; rejects accessors/toJSON.
- Binary data: genuine standard `Uint8Array` (ArrayBuffer.isView, fixed backing ArrayBuffer, offset 0, full view) or native `Blob` (Blob.prototype.size getter); verified via native intrinsic getters without invoking own/subclass overrides; rejects SharedArrayBuffer, resizable, detached, or Proxy.
- Cumulative `byteLength === actualBytes <= maxBytes`. Returns fresh frozen array with fresh frozen wrappers; retains data reference without freezing binary.

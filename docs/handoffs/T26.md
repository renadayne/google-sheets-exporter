# T26 — Safe Single-Rectangle CSV Row Encoder

Status: PASS.

## Implementation Overview

Updated the pure safe single-rectangle CSV row encoder in `src/export/csv.ts` and tests in `tests/unit/csv.test.ts` per review corrections:

1. **Required AbortSignal & Shape Validation**:
   - `EncodeCsvOptions.signal` is a required `AbortSignal`.
   - Validates signal shape (`aborted: boolean` and `addEventListener: function`); rejects missing/malformed signals with `CONFIG_INVALID`.
   - Propagates static `DomainError('OPERATION_ABORTED')` on abort, keeping sensitive error reasons/tokens out of diagnostics.

2. **Lazy Bounded Empty-Row Caching**:
   - Empty-row template size calculated as `3 * cols + 1` bytes. Cached lazily only if `size <= 64KiB` (65,536 bytes) upon encountering the first blank row.
   - For wider blank rows (e.g. 30,000 columns), emits constant `EMPTY_QUOTES`, `COMMA_BYTES`, and `CRLF_BYTES` directly through `ByteAccumulator` without materializing template arrays, strings, or `rowParts`.
   - 1x30000 blank-row test verified with independent `csv-parse` and asserts no >64KiB `TextEncoder.encode` calls.

3. **Field Escaped UTF-8 Byte Preflight**:
   - `preflightCellBytes` iterates Unicode code points/units calculating exact escaped byte requirements (framing quotes, doubled double quotes, and `apostrophe_prefix_v1`) against `ByteAccumulator.remainingBytes`.
   - Rejects with `BYTE_LIMIT_EXCEEDED` immediately once budget is exceeded, before calling `formatCell` or allocating oversized escaped strings or `Uint8Array` buffers.
   - Verified with CJK and quote-heavy strings whose JS length fits budget but escaped UTF-8 bytes exceed it, proving zero oversized encoder calls. Source data cells remain typed, exact, and unmutated.

4. **Accurate Cancellation Classification**:
   - Mid-loop cancellation is verified via row-boundary polling against a proxy signal.
   - Accurately distinguished: this is synchronous code polling between row iterations; true preemptive termination of synchronous operations requires host/worker thread termination (`worker.terminate()`), pending T36.

## Checks Run

- Strict TypeScript check: `npm run typecheck` (`tsc --noEmit`) -> PASS (0 errors, exit code 0).
- Targeted Vitest suite: `npm test -- tests/unit/csv.test.ts` -> PASS (13/13 tests, 241ms, exit code 0).
  - Exact Unicode, commas, quotes, CRLF, tabs, and whitespace preserving `'00123'`.
  - Nonzero-origin `C5:D6` emitting 2x2 with blank gaps.
  - Typed numeric negatives without prefix, booleans `TRUE`/`FALSE`, date serial numbers, and inert error text.
  - Dangerous string corpus and exact transform counts under `apostrophe_prefix_v1`; source cells unmutated.
  - Sparse A1='00123', D50='middle', Z90000=42 on demand (90,000 rows verified with independent `csv-parse/sync`).
  - 1x30000 blank row regression without caching >64KiB template or making oversized TextEncoder calls.
  - Escaped UTF-8 field byte preflight for CJK and quote-heavy strings before allocation.
  - Exact byte cap vs cap - 1 boundary enforcement.
  - BigInt preflight rejection of enormous empty rectangle.
  - Rejection of duplicates, out-of-bounds, invalid coordinates, and empty rectangles.
  - Rejection of bad types, NaN, Infinity, Date objects, and lone surrogates.
  - Signal shape validation, token leak prevention, and static `OPERATION_ABORTED`.
  - Row loop boundary cancellation code polling across independent repeated calls.

## Limitations & Pending Work

- Primitive single-rectangle row encoder only: no multi-sheet ZIP framing, WriterPort, manifest metadata, or UI integration (pending T27/T31).
- Cancellation relies on synchronous polling at row boundaries; caller-side worker isolation and preemptive interruption pending T36.
- Spreadsheet importer compatibility (Excel/LibreOffice) and live tenant evidence remain unverified/pending.

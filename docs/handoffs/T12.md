# T12 — Pure A1 Notation Parser and Canonical Bounds Resolution

Status: **PASS for offline pure A1 parsing and canonical bounds resolution (T12)**.

## Delivered Files

- `src/source/a1.ts`:
  - `parseA1(input: string, sheet: SheetMeta): Rect`: Pure parser resolving range strings into zero-based half-open intervals `[r0, r1) x [c0, c1)`.
  - Supported Range Syntax:
    - Single cell: `A1`, `z90000`, with optional `$` notation (`$A$1`, `$A1`, `A$1`). Resolves to `[r, r + 1) x [c, c + 1)`.
    - Bounded rectangle: `C5:D6`, `A1:Z90000`, `$C$5:$D$6`, `c5:d6`. Resolves to `[r0, r1_raw + 1) x [c0, c1_raw + 1)`.
    - Whole-column range: `B:D`, `A:A`, `$B:$D`. Resolves to full allocated sheet rows `[0, sheet.rows) x [c0, c1_raw + 1)`.
    - Whole-row range: `5:6`, `1:1`, `$5:$6`. Resolves to full allocated sheet columns `[r0, r1_raw + 1) x [0, sheet.columns)`.
  - Sheet Title Prefix Support:
    - Quoted syntax with doubled apostrophe escaping, unicode/emoji, spaces, and literal `!` inside titles: e.g. `'O''Brien !😀'!$A$1`, `'Café & Data!'!C5:D6`.
    - Unquoted simple sheet titles matching Unicode identifier grammar `/^[\p{L}_][\p{L}\p{N}_]*$/u`: e.g. `SparseTab!A1`, `Bảng_1!B:D`.
    - Exact matching required against `sheet.title`; sheet mismatch or cross-sheet ranges (`'Sheet1'!A1:'Sheet2'!B2`) fail immediately.
    - Optional sheet title prefix: ranges without prefix are resolved directly against the selected sheet.
  - Invariants & Error Handling:
    - Rejects ambiguous bare single column/row tokens (`A`, `1`, `$B`, `$5`), empty strings, and whitespace-only strings with `RANGE_INVALID`.
    - Rejects named ranges, unions/comma/semicolon (`A1,B2`), R1C1, reversed endpoints (`D:B`, `6:5`, `D5:C4`, `D5:C5`, `C6:C5`), mixed endpoint kinds (`A1:B`, `A:B2`, `1:A2`), negative/zero/overflow rows (`A0`, `A-1`, `A01`), unsafe column conversions, and workbook references (`[Book1]Sheet1!A1`) with `RANGE_INVALID`.
    - Coordinates that are syntactically valid but exceed known allocated grid boundaries (`sheet.rows`, `sheet.columns`) throw `RANGE_OUT_OF_BOUNDS`.
    - Non-GRID sheets (`OBJECT`, `DATA_SOURCE`) or missing/zero/negative/unsafe sheet dimensions throw `SOURCE_UNSUPPORTED`.
    - Safe error messages: bare source strings and tokens are never echoed into `DomainError` instances.
    - Preserves input metadata; no mutations, no network, and no hard Excel limits (1,048,576 rows or 16,384 columns) enforced.
- `tests/unit/a1.test.ts` (59 unit tests):
  - Single cell coordinates, lowercase insensitivity (`a1`, `z90000`), exact last cell (`Z90000`), and `$` notation combinations.
  - Bounded rectangles: `C5:D6 => r0=4, c0=2, r1=6, c1=4`, identical cell rectangles (`C5:C5`), and full-grid `A1:Z90000`.
  - Exact column transition boundaries tested against independent literals: Z (25) -> AA (26), AZ (51) -> BA (52), ZZ (701) -> AAA (702), and whole-column transition ranges `Z:AA`, `AZ:BA`.
  - Whole-column expansion across allocated rows and whole-row expansion across allocated columns.
  - Quoted and unquoted sheet prefixes with doubled apostrophes, emoji, literal `!`, spaces, and Unicode.
  - No hard Excel caps: verified against mocked sheet with 2,000,000 rows and 20,000 columns (`A1500000`, `XFE1`, `XFE:XFE`).
  - Input immutability verified against `Object.freeze(sheet)`.
  - Comprehensive negative coverage: `RANGE_INVALID` (syntax, prefix mismatch, cross-sheet, bare tokens, unions, R1C1, reversed, mixed kinds, overflow digits/letters), `RANGE_OUT_OF_BOUNDS` (exceeding rows/cols on large and small sheets), and `SOURCE_UNSUPPORTED` (non-GRID, missing, zero, float, NaN, infinite dimensions).
  - Asserts raw input tokens are never echoed in `DomainError.message`.

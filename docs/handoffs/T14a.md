# T14a — Deterministic 2D Tiling and Binary Splitting

Status: **PASS for offline deterministic 2D tiling and binary chunk splitting (T14a)**.

## Delivered Files

- `src/domain/chunks.ts` (151 lines):
  - `PlannedChunk`: Readonly interface `{ id: string, rect: Rect }`.
  - `createChunkId(rect: Rect): string`: Deterministic stable chunk ID generator (`chunk_${sheetId}_${r0}_${c0}_${r1}_${c1}`) encoding sheet and absolute coordinates; distinct for parent vs children; no random or clock dependencies.
  - `DEFAULT_MAX_POSITIONS = 20_000`: Provisional, uncalibrated default position budget (clearly documented pending T06/T41 benchmarks).
  - `planChunks(rect: Rect, maxPositions?: number): readonly PlannedChunk[]`:
    - Pure function that deterministically partitions a half-open rectangle `[r0, r1) x [c0, c1)` into chunks with area `<= maxPositions`.
    - Preserves absolute offsets; emits chunks in deterministic row-major order.
    - Uses full-width row tiling when width fits budget; performs column tiling when `width > maxPositions`.
    - Strictly avoids dense cell allocation or early termination based on cell contents.
  - `splitChunk(chunk: PlannedChunk): readonly [PlannedChunk, PlannedChunk]`:
    - Deterministically splits a chunk into two non-overlapping children whose exact union equals parent.
    - Axis rule: splits longer dimension; ties are broken towards rows.
    - Midpoint safely computed from difference (`r0 + Math.floor(height / 2)` or `c0 + Math.floor(width / 2)`).
    - Cannot split 1x1 chunk; throws `DomainError('RANGE_INVALID')`.
  - Strict input validation:
    - Rejects negative, fractional, non-finite, and unsafe coordinates with `RANGE_INVALID`.
    - Rejects reversed intervals (`r1 < r0 || c1 < c0`) with `RANGE_INVALID`.
    - Rejects empty intervals (`r1 === r0 || c1 === c0`) with `RANGE_EMPTY`.
    - Rejects unsafe total position products with RANGE_INVALID; only exact safe integer counts are supported.
    - Rejects invalid budgets (`budget < 1` or non-safe integer) with `RANGE_INVALID`.
    - Returns frozen chunks and rects; preserves caller inputs without mutation.
- `tests/unit/chunks.test.ts` (209 lines, 10 tests):
  - Literal expected small tiles with nonzero origin and column tiling when wide rect exceeds budget.
  - Exact budget and budget=1 boundary cases.
  - A1 and sparse Z90000 bounds/membership arithmetic verification without dense cell enumeration.
  - Rejection of empty, reversed, fractional, negative, non-finite, and unsafe coordinates/budgets.
  - Binary splitting of 1xN, Nx1, odd dimensions (tie breaking to rows), nonzero origins, and 1x1 error rejection.
  - Deep-freeze immutability, stable IDs distinguishing children/parent, and zero input mutation.
  - Independent seeded randomized small cases using `createDeterministicRandom`, enumerating coordinates into Sets to assert exact 1:1 coverage with no outside coordinates and each chunk area `<= budget`.

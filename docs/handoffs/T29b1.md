# T29b1 — Pure XLSX Numeric and Text Linefeed Representability Guards

Status: PASS.

## Implementation Overview
Updated `src/export/xlsx-guards.ts` (+32 lines) and `tests/unit/xlsx-guards.test.ts` (+50 lines):
- **Constants & Primary Source**:
  - `XLSX_MAX_LINE_FEEDS = 253`, `XLSX_MIN_NUMERIC_MAGNITUDE = 2.2251e-308`, `XLSX_MAX_NUMERIC_MAGNITUDE = 9.99999999999999e307`, `XLSX_MAX_SIGNIFICANT_DIGITS = 15` cited from [Excel specs](https://support.microsoft.com/en-us/excel/excel-specifications-and-limits). Source formulas remain inert strings.
- **Number Guard (`assertXlsxNumberRepresentable`)**:
  - Rejects non-primitives, non-finites, and out-of-range magnitudes with static `FORMAT_UNSUPPORTED`.
  - Allows zeros (`+/-0`).
  - Screen enforces `<=15` significant decimal digits on shortest canonical mantissa `String(abs(value))` after stripping decimal point and leading/insignificant trailing zeros.
  - Conservative risk screen: no silent rounding, string conversion, or Date coercion.
- **Text Guard Linefeed Extension**:
  - Counts LF (`0x0A`) codepoints in bounded loop; CRLF counts as one LF. Fails `FORMAT_UNSUPPORTED` when line feeds exceed 253 while preserving text without mutation.

## Delivered

  - Readonly discriminated `WorkerRequest` (`BEGIN`, `APPEND`, `FINALIZE`, `CANCEL`) and `WorkerResponse` (`ACK`, `PROGRESS`, `STAGED_ARTIFACTS`, `ERROR`, `CANCELLED`) unions.
  - `WorkerJobEnvelope`: requires `protocolVersion: 1`, `jobId: string`, `generation: number`.
  - Forbids auth and principal fields via optional `never` (`principalKey`, `displayEmail`, `email`, `principal`, `token`, `accessToken`, `refreshToken`, `authorization`, `headers`, `account`, `auth`, `exportRequest`) to reject structurally typed contaminated variables on envelopes and requests.

  - `ERROR` carries safe `ErrorCode` with optional explicit numeric coordinates (`sheetId`, `r`, `c`); explicitly forbids arbitrary `message`, `stack`, `body`, or `cause` objects.
  - Documented T36 runtime obligations: validate version/type, identifiers and finite integer generation, chunk.jobId matching envelope, expected active generation, context whitelist and bounds; note that TS alone is not runtime/privacy validation.

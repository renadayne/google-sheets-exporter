## Delivered Files

- `src/domain/scope.ts`:
  - `buildScopePlan(source: SourceRef, workbook: WorkbookMeta, account: AccountContext, options: ScopeOptions): ExportRequest`:
    Pure function resolving spreadsheet source, workbook metadata, account context, and scope options into a deeply frozen `ExportRequest`.
  - Invariants and semantics:
    - **Source binding**: Enforces `source.spreadsheetId === workbook.id` (`SOURCE_UNSUPPORTED`). Binds metadata; does not prove permission.
    - **Highlight independence**: `source.highlightedSheetId` is purely a UI hint and is ignored for tab selection.
    - **Source ordering**: All selected scopes are strictly ordered by source `sheet.index`, regardless of numeric IDs or caller input order.
    - **Default selection**: Omitting `selectedSheetIds` defaults to all visible tabs (`!sheet.hidden`), including visible empty tabs. Hidden tabs require explicit opt-in.
    - **Reviewed semantic decision**: `api_visible` excludes hidden tabs, yet explicit selection must never be silently dropped. Therefore, explicitly selecting a hidden tab with `visibility: 'api_visible'` throws `SOURCE_UNSUPPORTED`. Callers must explicitly specify `visibility: 'include_all'` to export hidden tabs. Default `api_visible` selects visible tabs. `include_all` alone does not auto-select hidden tabs without explicit selection. No automatic mode switch occurs.
    - **Non-poisoning isolation**: Unselected non-GRID or hidden tabs do not poison an otherwise valid selection. Selecting an unsupported tab (non-GRID, zero/negative/invalid rows or columns) throws `SOURCE_UNSUPPORTED`. Unsupported selected tabs are never silently skipped.
    - **Per-tab ranges**: Optional A1 range per selected tab parsed via reviewed `parseA1`, yielding exactly one `Rect` per tab. Unspecified tabs default to full allocated grid `[0, rows) x [0, columns)`. Duplicate range entries and ranges for unselected tabs throw `RANGE_INVALID`.
    - **Immutability**: Deeply freezes copied output (`ExportRequest`, `scopes`, and `Rect` objects); caller inputs are never mutated or frozen.

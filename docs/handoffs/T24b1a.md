# T24b1a — Shared Writer Context and Geometry Validation

Status: PASS.

## Implementation Overview

Implemented pure shared writer context and geometry validation in `src/export/coverage.ts` and targeted test suite in `tests/unit/writer-coverage.test.ts` as the prerequisite for T24 JSON export, incorporating tech lead review corrections:

1. **Option and Cap Guards**:
   - Single-access capture: captures `maxChunks` and `signal` once inside safe config `try` block, preventing double getter evaluation, raw leakage, or parameter mutation.
   - Real `AbortSignal` shape validation: verifies `aborted: boolean` and `addEventListener` / `removeEventListener` methods. Throws `CONFIG_INVALID` on non-conforming signal objects and static `DomainError('OPERATION_ABORTED')` on pre-abort.
   - Enforces `maxChunks` positive safe integer cap `<= 4096` as a provisional pairwise resource guard.
   - Rejects empty chunk lists with `FORMAT_SERIALIZATION_FAILED` and cap overages with `SIZE_LIMIT_EXCEEDED` before expensive pairwise checks.

2. **Sanitized Context & Key Whitelisting**:
   - `hasExactKeys`: explicitly verifies every `Object.keys` entry exists in whitelist, rejects any symbol keys, and verifies every expected key is an own property. Prevents sneak-in of unknown enumerable properties (e.g. `accessToken`) when an expected key is defined as non-enumerable.
   - Whitelists exact own enumerable keys on `WriterContext`: `sourceId`, `title`, `locale`, `timeZone`, `scopes`, `mode`, `format`, `visibility`, `limitsVersion`, `sheetOrder`, `sheets`. Rejects extra properties, credentials, or principal keys.
   - Validates exact enums, non-empty identifiers, aligned array lengths across scopes/sheets/sheetOrder, non-duplicate sheet IDs/source indices, strictly ascending source indices, and structural shape of GRID sheet metadata and scopes.
   - Rejects `hidden: true` tabs requested under `visibility: 'api_visible'` and negative-zero coordinates (`-0`).

3. **Geometry and Partition Proof**:
   - Validates chunk shapes (`jobId`, `chunkId`, `rect`, `cells`, `excludedIntervals`, `byteCount`), requiring shared nonempty `jobId`, unique `chunkId`s, and chunk rects inside scope boundaries. Deep cell and exclusion validation is explicitly deferred.
   - Proves exact 2D partition per sheet via pairwise non-overlap (`Math.max < Math.min`) and BigInt area sum matching scope area without grid materialization. Detects equal-area overlap+gap traps.
   - Cooperative cancellation polling: polls `signal.aborted` inside the pairwise inner loop every 128 comparisons (`(comparisonCount & 127) === 0`). Does not claim preemptive synchronous cancellation.

4. **Error Sanitization & Hostile Getter Protection**:
   - Uses `toSafeDomainError` to rebuild pristine `DomainError` instances when catching domain errors, stripping any hostile getter's mutated message, cause, or extra properties.
   - Generic exceptions map strictly to static `CONFIG_INVALID` (in config guard) or `FORMAT_SERIALIZATION_FAILED` (in main validation).

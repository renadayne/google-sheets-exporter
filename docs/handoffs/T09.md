## MV3 CSP Caveat

Ajv8 compiles schemas dynamically via `Function()`, which is prohibited under Chrome Extension Manifest V3 Content Security Policy (`script-src 'self'`). Ajv and ajv-formats are strictly dev-only dependencies for Node tests. They must **never** be imported into extension runtime code (`src/runtime/`, `src/jobs/`, `src/export/`, `src/source/`).

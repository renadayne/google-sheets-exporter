## Summary
- Implemented `encodeFrozenJson(value, options): Uint8Array` for deeply frozen plain JSON data with two-pass encoding.
- Exported provisional resource guards: `MAX_JSON_DEPTH = 32` and `MAX_JSON_NODES = 4_000_000` (`SIZE_LIMIT_EXCEEDED`).
- Pass 1 validates structure and counts exact UTF-8 bytes without `JSON.stringify`, `TextEncoder`, or token copies. Reuses `countJsonStringBytes` for strings and object keys against remaining byte budget.
- Early resource checks: array length > node budget or min punctuation + 1-byte value budget fails immediately before key list allocation.
- Rejection of malformed trees (`FORMAT_SERIALIZATION_FAILED`): unfrozen objects/arrays, accessors (getters/setters rejected without invocation; 0 calls), `toJSON` hooks (0 calls), array holes, non-enumerable properties, extra array keys, symbols, custom prototypes, `Date`, `undefined`, functions, `BigInt`, nonfinite numbers, and object/array cycles via `WeakSet` ancestry.
- Accepted structures: shared frozen references across branches and null-prototype objects.
- Pass 2 allocates one exact `Uint8Array`, writes ASCII direct (numbers with `-0 -> 0`, bools, null, punctuation), and uses `TextEncoder.encodeInto(JSON.stringify(str), out.subarray(offset))` for primitive strings only after preflight. Verifies final count equals preflight.
- AbortSignal polled per node and before return; static preabort checked. Safe sanitization via `toSafeDomainError` without value or message leakage.

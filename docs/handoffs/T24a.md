# T24a — Precompiled Static Schema Validation Infrastructure

Status: PASS.

## Implementation Overview

Precompiled static schema validation infrastructure for `ExportReport` and `JsonExportDocument` conforming to Architecture §G, `docs/json-schema.md`, and MV3 CSP restrictions:

1. **Build-time generator (`scripts/generate-validators.mjs`, `scripts/generate-validators.d.mts`)**:
   - Uses locked `Ajv2020` (v8.20.0), `ajv-formats` (v3.0.1), and `standaloneCode`.
   - Compiles Draft 2020-12 schemas with strict validation, first-error runtime failure, and no coercion/defaults/removal. Dev parity tests still collect all errors.
   - Bundles standalone code and pure runtime helpers (`ucs2length`, `equal`, date-time format) via Vite 8 Node API into a single self-contained ES2022 ESM artifact.
   - Enforces deterministic LF line endings and includes SHA-256 canonical input/settings hash header with MIT license notices for Ajv and ajv-formats.
   - Provides `--check` mode failing on missing or stale output without rewriting.
2. **Generated artifacts (`src/contracts/generated/validators.js`, `validators.d.ts`)**:
   - Single 156KB self-contained ESM bundle exporting `validateReport` and `validateExport`.
   - Zero external imports, zero runtime `require()`, zero dynamic code generation (`Function`/`eval`).
   - Own accurate TypeScript declarations without external Ajv type leakage.
3. **Safe runtime wrapper (`src/contracts/validation.ts`)**:
   - Exports type guards `isExportReport(input: unknown): input is ExportReport` and `isJsonExportDocument(input: unknown): input is JsonExportDocument`.
   - Imports exclusively the local generated module and domain types; no schema compiler runtime imports.
   - Suppresses raw schema error exposure, resets generated `.errors` property to `null` in `finally`, safely returns `false` on hostile getter throws, and performs no object mutation or type coercion.
4. **NPM scripts (`package.json`)**:
   - Added `schemas:generate`, `schemas:check`, and `prebuild` (`npm run schemas:check`).
5. **Documentation (`docs/json-schema.md`)**:
   - Clarified build-time static bundling and safe wrapper boundary under MV3 CSP rules.

# T08b — Port Contracts and Safe Domain Errors

Status: **PASS for offline ports and errors contracts after tech-lead corrections**.

## Delivered

- `src/contracts/ports.ts`:
  - `AuthPort`: `signIn`, `getContext`, `getToken`, `signOut`. Tokens stay in auth/network memory; `getToken` requires binding to expected principal key.
  - `PermissionPort`: `check(source, account, signal)` returning `Eligibility`. Prior positive cache alone does not authorize publication.
  - `SheetsPort`: `getMetadata` and `readGrid` strictly requiring explicit `SourceRef` and active `PermittedEligibility` + `AbortSignal`. Raw grid transport payload is `unknown` with `byteCount`, never `any`.
  - `WriterContext` includes selected sheet metadata/order and forbids auth/header fields via optional never. Strong negative fixtures spread auth data onto otherwise-valid contexts to prove structural rejection. Writer finalization receives the final metadata report and signal; outputs remain private. Abort stays callable after the job signal is cancelled.
  - `SourceObservationPort.observe` supplies non-atomic version/modifiedTime observations. All operational methods have explicit signals. Download errors are safe ErrorCode values; Clock/Random each have one authoritative method.
  - `DownloadPort`: `publish(artifacts, signal)` returning `DownloadResult[]` with `completed` | `interrupted` per-file status; controller final gate is sole publication authority.
  - Deterministic test utilities: `Clock`, `Random`, and `Fetch` interfaces without broad generic state.
- `src/contracts/errors.ts`:
  - Concise stable `ErrorCode` union spanning 14 categories (`config`, `auth`, `admin`, `restricted`, `uncertain`, `source`, `range`, `size`, `format`, `quota`, `network`, `cancel`, `changed`, `internal`).
  - Fixed safe `SAFE_ERROR_MESSAGES` catalog by code.
  - `DomainError` class and `toSafeDomainError` sanitizer: strictly discards arbitrary `Error.message`, raw HTTP bodies, cause objects, and token strings. Maps unknown errors to `INTERNAL_ERROR`.
  - `RetryClassification` (`none`, `network`, `rate_limit`, `auth_refresh`) and `isRetryable` helper.
- `tests/unit/errors.test.ts`: 12 focused tests including mutated DomainError properties and hostile getters. Safe conversion reconstructs a fresh catalog error, never returns an untrusted original instance; retry class is fixed by code and cannot be caller-overridden. CONFIG_REQUIRED matches the scaffold configuration state.
- `tests/types/port-contracts.ts`: Compile-only type fixtures testing port implementations and verifying compile-time rejection of auth-bound `ExportRequest`, `AccountContext`, and unpermitted eligibility.

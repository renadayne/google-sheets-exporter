# T36b1 — Safe worker request envelope parser

Bounded prerequisite: safe outer command envelope parser for dedicated export worker requests.

Files:
- `src/runtime/worker-envelope.ts`
- `tests/unit/worker-envelope.test.ts`
- `docs/handoffs/T36b1.md`

`parseWorkerCommand(input: unknown): ParsedWorkerCommand | null` validates the outer envelope across the worker boundary:
- Requires plain own record (`Object.prototype` or `null`), rejecting arrays, classes, primitives, and own Symbol properties.
- Rejects envelope accessors without invocation by inspecting own property descriptors.
- Enforces closed exact keys: `protocolVersion` (1), `jobId` (non-empty opaque string preserved verbatim), `generation` (safe integer >= 0, rejecting `-0`), `type` (`BEGIN`, `APPEND`, `FINALIZE`, `CANCEL`), plus variant payload slots (`context`, `chunk`, `report`, none for `CANCEL`).
- Rejects non-enumerable masks, inherited required fields/extras, and forbidden auth/credential fields even if undefined.
- Captures each descriptor value once.
- Returns a fresh frozen known-field envelope while preserving payload reference identity.
- Payloads remain typed `unknown` and are never traversed, cloned, frozen, or asserted. Hostile proxies/traps fail safely to `null`.
- Existing ping scaffold remains untouched.

# T11 — Pure source identification

Status: reviewed PASS for offline parsing.

`identifySource(input)` accepts a trimmed opaque ASCII ID (`letters/digits/_/-`, no fixed length), or an HTTPS URL at exact `docs.google.com` with no credentials/nondefault port. Supported paths are `/spreadsheets/d/{id}` and `/spreadsheets/u/{decimal-index}/d/{id}`, optionally followed by `/edit`, `/view`, `/preview` and a trailing slash. Published links and other suffixes are unsupported.

One canonical nonnegative safe decimal `gid` may appear in query or fragment. Duplicates, conflicts, leading zeros, malformed values and overflow fail. Return contains only spreadsheetId and optional highlightedSheetId; account path/authuser never creates an account context. Unknown harmless parameters are ignored. Raw/path normalization tricks, backslashes, embedded controls and encoded path separators/dots are rejected before URL normalization. Errors use static SOURCE_UNSUPPORTED messages.

Reviewer corrected malformed HTTPS authority normalization, terminal Unicode whitespace in gid, bounded numeric parsing, and overbroad rejection of encoded harmless query values. No API existence/access verification, network, tab access, auth or selection behavior is implemented.

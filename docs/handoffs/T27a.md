## Summary
Implemented pure multi-sheet CSV batch encoder `encodeCsvSheets` and exported interface `CsvSheetBytes`:
- Validates options once (`maxBytes` safe non-negative <= 64MiB provisional, valid `signal`, static pre-abort).
- Requires non-empty prepared array (`FORMAT_SERIALIZATION_FAILED` on empty/missing).
- Maps filenames in source input order with reviewed `mapCsvFilenames`, preserving stable IDs and disambiguating collisions.
- Encodes each prepared sheet via `encodeCsv`, cumulatively deducting bytes from remaining budget without partial return.
- Retains original full rectangle dimensions including dense blank rows/columns for API-visible exclusions and empty tabs.
- Returns newly frozen wrappers, copies of mappings, owned encoder byte buffers, and exact transform metadata (`apostrophe_prefix_v1`, `totalTransformedCells`, `bySheet`).
- Polls abort signal between sheets and before return; clears local references on error and re-throws safe rebuilt `DomainError`.

## Summary
Implemented pure byte-transport CSV ZIP encoder `encodeCsvZip`:
- Pure transport encoder: preserves byte payloads and filenames; does not validate report metadata or authorize publication.
- Validates options: `maxUncompressedBytes` (0..64MiB), `maxBytes` (0..128MiB), rejects `-0`, verifies AbortSignal. Config getter failures throw static `CONFIG_INVALID`.
- Validates 2..4096 `CsvSheetBytes` records and non-empty `manifestBytes`. Verifies single-capture canonical `.csv` filenames via `formatWorkbookArtifactFilename`, rejecting traversal, backslashes, reserved devices, and case/NFC collisions.
- Aggregates uncompressed byte length before ZIP allocation; rejects with `BYTE_LIMIT_EXCEEDED` if exceeding `maxUncompressedBytes`.
- Packages entries via genuine `zipSync` into null-prototype dictionary in caller source order with `manifest.json` last. Applies deterministic DOS timestamp (`1980-01-01 00:00:00`) and level 6 compression.
- Enforces `maxBytes` on final archive size. Copies freshly owned Uint8Array output.
- Signal polling before/after `zipSync` and loops. Outer error boundary preserves trusted `DomainError` codes and maps untrusted errors to `FORMAT_SERIALIZATION_FAILED`.

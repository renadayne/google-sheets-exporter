# T36b3 — Safe worker reply envelope parser

Safe outer response envelope parser for dedicated export worker replies.

Files:
- `src/runtime/worker-reply-envelope.ts`
- `tests/unit/worker-reply-envelope.test.ts`
- `docs/handoffs/T36b3.md`

`parseWorkerReply(input: unknown): ParsedWorkerReply | null` validates replies across the worker boundary:
- Requires plain own record (`Object.prototype` or `null`), rejecting arrays, classes, primitives, symbols, accessors.
- `Reflect.ownKeys` bounds keys (4..8) before reading data descriptors once; no re-reads or `hasOwnProperty` re-traps.
- Closed exact keys:
  - `CANCELLED`: exact 4 base keys (`protocolVersion: 1`, non-empty `jobId`, safe `generation >= 0` rejecting `-0`, `type: 'CANCELLED'`).
  - `ACK`: base plus optional `phase` (begin/append/serializing/finalizing), safe integer `chunksCompleted`, `totalChunks` (`total >= completed`); undefined rejected; absent omitted; no percent/percentage.
  - `PROGRESS`: requires `phase`, `chunksCompleted`; optional `totalChunks >= chunksCompleted`.
  - `ERROR`: requires catalog `code`; optional independent safe integer coords (`sheetId`, `r`, `c`, no -0); rejects `message`, `stack`, `body`, `cause`, `error`.
  - `STAGED_ARTIFACTS`: exact base + `artifacts` slot typed `unknown`. Untraversed, uncloned, unfrozen, preserving reference identity.
- Rejects auth fields and prototype pollution via `has` checks. Returns fresh frozen wrapper without freezing input.

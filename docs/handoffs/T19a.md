    - 2xx: `{ kind: 'success' }` (data parsing is adapter responsibility).
    - 401: `{ kind: 'renew_auth', code: 'AUTH_EXPIRED' }` (candidate for single re-auth; never transport retry).
    - 404: `{ kind: 'fail', code: 'SOURCE_NOT_FOUND' }` (missing or inaccessible).
    - 408: `{ kind: 'retry', code: 'NETWORK_TIMEOUT' }`.
    - 429: `{ kind: 'retry', code: 'RATE_LIMITED' }`.
    - 5xx: `{ kind: 'retry', code: 'NETWORK_SERVER_ERROR' }`.
    - 403: Strictly parses Google machine `error.errors[].reason` fields without freeform substring matching. `rateLimitExceeded` / `userRateLimitExceeded` -> retry `RATE_LIMITED`. `domainPolicy` -> fail `ADMIN_RESTRICTED` (overrides rate reasons). `dailyLimitExceeded` -> fail `QUOTA_EXCEEDED` (terminal; overrides rate reasons). Malformed, missing, empty, or mixed-with-unknown reasons fail closed as `UNCERTAIN_PERMISSION`. No body, header, or token text echoed in decisions.
    - Other HTTP statuses: `{ kind: 'fail', code: 'SOURCE_UNSUPPORTED' }`.
    - Non-integer or out-of-range status: `{ kind: 'fail', code: 'INTERNAL_ERROR' }`.
  - `parseRetryAfterMs(header, nowMs)`:
    - Parses nonnegative integer delay-seconds, including zero; fractional syntax is rejected per RFC 9110.
    - Parses strict IMF-fixdate GMT headers with calendar validation against day names.
    - Past timestamps return `0`.
    - Giant numeric delays safely saturate at `Number.MAX_SAFE_INTEGER`.
    - Malformed dates/headers or non-finite `nowMs` return `null`.
  - `computeRetryDelayMs(failedAttempt, retryAfterMs, remainingBudgetMs, random)`:
    - Reviewed 4-attempt client policy: returns `null` for attempt >= 4 without consuming RNG.
    - Base retry backoff: 1000ms, 2000ms, 4000ms after failed attempt 1, 2, 3 plus additive jitter `floor(random.next() * 250)ms`.
    - Enforces RNG output in `[0, 1)`. Rejects invalid inputs (`failedAttempt < 1`, non-integers, invalid random, negative retry-after, non-finite budget) with safe `DomainError('CONFIG_INVALID')`.
    - Required wait is `max(jitteredBackoff, validRetryAfter)`.
    - Delay must fit strictly inside `remainingBudgetMs` (`requiredWait < remainingBudgetMs`); equal boundary returns `null`. Never clamps server delays downward.

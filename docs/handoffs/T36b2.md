# T36b2 — Dedicated Worker Session Dispatcher

Bounded prerequisite: worker session dispatcher managing job lifecycle, monotonic generation fences, validated writer dispatching, and sanitized response emission.

- `tests/unit/worker-session.test.ts`

Dispatcher features & review corrections:
- `createWorkerSession(deps)` returns frozen `{ handle, close }`.
- Envelope validation: `parseWorkerCommand` validates outer boundaries; invalid envelopes and primitives are dropped.
- Generation reservation & identity installation: monotonic watermark (initially -1). BEGIN installs reserved identity immediately before helpers/callbacks and aborts old jobs. Fences check `isCurrent` after each step (`snapshotWriterContext`, `createWriter`, `begin`). A factory writer returned after being superseded or closed is aborted and discarded immediately.
- Fences before writer calls: FINALIZE PROGRESS emission is followed by an ownership fence so that callback throws, closes, cancellations, or new BEGINs prevent `writer.finalize`. APPEND descriptor capture is fenced before failure/append so proxy traps cannot append or fail stale jobs. Redundant `hasOwnProperty` loop removed; 6 own enumerable data fields captured once.
- Robust cleanup: `abortAndDetach` detaches identity before abort callbacks, handles both synchronous throws and promise rejections, and guards `abortedWriter` against double aborts. Synchronous throw in `writer.abort` does not drop CANCELLED.
- Safe emissions: non-terminal emissions require `isCurrent(job)`. Terminal emissions (`CANCELLED`, `STAGED_ARTIFACTS`, `ERROR`) check `!isClosed && job.generation === highestAcceptedGeneration` so valid terminals are not suppressed while stale errors after newer jobs are dropped.
- `close()` is idempotent, permanent, and observes all rejections and synchronous throws.
